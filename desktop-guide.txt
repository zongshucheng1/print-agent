德勤打印客户端 0.6.3（Windows 64 位）

从左侧“打印机”打开设备列表，点“新增打印机”后选择“USB 直连”或“局域网打印机”。切换到“运行状态”可查看服务、设备数量、待补报回执和任务记录。界面按 Windows 显示缩放调整字体、图标和间距，内容超出窗口时可拖动滚动条。
“连接配置”用于检查服务器连接、管理机器接入密钥和任务领取开关。
首次打开“客户端日志”会自动读取 agent.log 最近 100 行，按记录时间倒序显示，最新日期和记录排在顶部。蓝色为 INFO，黄色为 WARNING，红色为 ERROR。双击一行可查看完整的脱敏文本。点击“刷新日志”后从最新记录开始阅读。

一、首次设置多打印机
1. 在 Windows 安装对应型号的厂家驱动。USB 打印机接上电脑后，先在 Windows 中确认能看到对应队列。
   在客户端添加局域网设备时可复用已有队列，也可按 IP 创建 RAW TCP 9100 队列。
   填写打印机 IP 并选择实际型号的驱动，队列名称可留空自动生成。
   IP 未知时，点击“搜索局域网打印机”，在“网段搜索”中选择本机网卡并搜索。已知 IP 时可切换到“按 IP 检查”。每次最多检查254个地址，可取消。已有网络队列可在“配置网络队列”右侧的“···”菜单选择。
   从结果表选中设备，点击“使用所选设备”回填新增页面，再确认驱动和队列名称。同 IP、端口和驱动的已有标准 TCP/IP 队列会复用。
   其他类型的打印机可以通过 Windows 添加。网络打印机可使用固定 IP 或 DHCP 地址保留。
   创建或搜索队列无需先配置后台或启动服务。随后在客户端登记时，服务会核验队列。
2. 后台“APP 管理 → 基础维护 → 电脑打印”选择工厂，登记多打印机客户端，保存一次性显示的接入密钥。
3. 客户端“连接配置”填写 HTTPS 后端根地址和接入密钥。
   本机隔离调试才使用 127.0.0.1 / ::1 HTTP。同源下载标签时，“标签文件来源”留空。
4. 勾选“允许领取并打印任务”并保存。此时尚无启用的打印机，不会因保存而出纸。
5. 到“运行状态”启动服务。首次需要 Windows 管理员授权；安装软件本身不启动打印服务。
6. 在“打印机”页添加设备。USB 打印机选择对应的已安装队列，局域网打印机选择已有或刚创建的队列。
   填写设备名称和安装位置后保存登记。服务账户会核验驱动、访问权限和 80 × 80 mm 纸张。新增设备默认暂停领取。
7. 后台为仓库选择这台电脑下的具体打印机。每仓库一个目标，多仓库可以共用一台。
8. 回客户端选择该打印机，点击“恢复领取”。总领取开关也必须已启用。
9. 后台创建测试标签，现场确认尺寸、内容和二维码后，确认启用仓库自动打印。
10. 重复第6至9步添加其他打印机。最多10台、最多4路同时提交，每台内部依次提交。

二、运行与暂停
关闭窗口不会停止服务。可以逐台暂停领取，其他打印机继续工作。
暂停仍检查旧任务和补报；Windows 已接受的任务仍可能继续出纸。
“运行状态”可按队列筛选任务。驱动报告完成不等于人工确认已出纸。
缺纸、离线或驱动无响应时检查所选打印机，不通过复制目录或删除SQLite解决结果不明。
断网后本机保存观察和回执，重连补报；没有服务端授权时不开始新的打印。
Windows打印系统故障可能影响全部队列，客户端不会自动清队列或重启系统服务。

三、查找、修改和删除打印机
在打印机列表输入设备名称、安装位置或本机可识别的 IP。USB 打印机可按名称或位置查找。清空搜索可查看完整列表。
选择设备后进入编辑，修改名称、位置或 Windows 队列并保存。有在途提交时需先暂停并等待收尾。
更换网络设备地址时，按新 IP 创建或复用 Windows 队列，核对驱动和目标后保存修改。
队列目标修改后重新核验和测试。旧任务保留原目标。
保存响应丢失时，“同步打印机”会恢复原请求结果，不要重复登记另一台。
删除前，在后台“电脑打印”对绑定该设备的仓库点击“暂停仓库自动打印”。回客户端选中设备，点击“暂停领取”。
等待在途任务结束后，选中设备并确认删除。已部署 0.4.3 配套后端及管理后台的环境具备所需的归档接口和仓库暂停操作。
删除后仍可在 Windows 使用该队列，历史任务和日志保留。
在Windows中直接改端口或换设备前，也应暂停并核查已有队列。

四、切换服务器与密钥
先停止服务，处理各打印机未收尾发送和待补报回执/观察，再点击“切换服务器”。
填写新地址和新密钥后“验证并切换”。目标服务器须登记v2客户端，成功后总领取默认关闭。
失败保留原配置；切回同一服务器复用原日志。不得用其他电脑/工厂的密钥覆盖当前身份。
同一服务器换密钥：停止服务，粘贴后台为原电脑重新配发的密钥，保存后启动。

五、数据与验证边界
安装时可分别为程序和数据选择文件夹。连接配置、机器凭据、打印任务记录和日志均使用选定的数据目录。
默认安装目录 C:\Program Files\Deqin\PrintAgent。
默认数据目录 C:\ProgramData\Deqin\PrintAgent\runtime。
同机覆盖安装时可以沿用原目录。更换数据目录时，选择本机磁盘上的新文件夹或空文件夹。安装程序复制现有数据并保留原副本。安装完成后从新快捷方式打开客户端，核对打印机列表，再到“运行状态”启动服务。
升级和卸载保留配置、凭据、任务与日志，不删除驱动和Windows队列。
自动观察与人工出纸确认分开。安装包未签名，发布时提供SHA256。
实物出纸须按现场打印机及耗材验收。
局域网搜索只查询本机接口可达子网，不修改设备 IP，也不提供厂家跨网段搜索；IP 不在可达网段时先用厂家工具调整。

本项目处于开发阶段，仅支持当前多打印机配置格式，不提供旧版本迁移或兼容入口。单台打印机也按多打印机列表配置。
